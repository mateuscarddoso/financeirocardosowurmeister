# ⚡ Quick Start - Sistema de Parcelamentos

## 🎯 Comece Agora em 5 Minutos

### 1️⃣ Iniciar o Servidor (1 min)

```bash
npm run dev
```

Você verá:
```
  VITE v4.5.14  ready in 463 ms
  ➜  Local:   http://localhost:5173/
```

### 2️⃣ Abrir no Navegador (30 seg)

Vá para: **http://localhost:5173/**

### 3️⃣ Fazer Login (30 seg)

- Senha: `417102a`
- Clique: **"Acessar"**

### 4️⃣ Ir para Parcelados (30 seg)

- Clique na aba: **"Parcelado"** (no menu principal)

### 5️⃣ Criar Primeiro Parcelamento (2 min)

#### Clique: "Novo Parcelamento" (botão roxo)

#### Preencha:
```
Descrição:        Sofá (ou qualquer produto)
Tipo:             Parcelado
Data Início:      (hoje)
Valor Mensal:     R$ 100,00
```

#### Clique em: "3x" (atalho)
- Sistema calcula: 3 parcelas
- Preview mostra: 3x de R$100 = R$300

#### Clique: "Criar Parcelamento"

#### Resultado:
- ✅ Card aparece com: "0/3 parcelas"
- ✅ Barra de progresso: 0%
- ✅ Valor total: R$300,00

---

## 🎬 O que Você Pode Fazer Agora

### 1. Acompanhar Progresso
- Navegue para próximo mês (`>`)
- Veja: "1/3 parcelas" (33%)
- Barra atualiza automaticamente

### 2. Editar Parcelamento
- Clique em **✏️** no card
- Altere o valor
- Clique em "Atualizar Parcelamento"

### 3. Deletar Parcelamento
- Clique em **🗑️** no card
- Confirmação
- Card desaparece

### 4. Ver Fluxo de Caixa
- Desça na tela
- Seção: "Parcelas nos Próximos Meses"
- Veja 12 meses futuros
- Cada mês mostra parcelas e total

### 5. Dashboard Principal
- Clique em "Gastos"
- Parcelas aparecem como gastos mensais
- Incluídas no saldo total

## ❓ Dúvidas Frequentes

### P: Como calcular o valor da parcela?
**R:** Divida o valor total pela quantidade. Ex: R$300 ÷ 3 = R$100/mês

### P: Posso mudar a data de início?
**R:** Sim! Edite e altere. O sistema recalcula automaticamente.

### P: O que acontece após a última parcela?
**R:** A parcela desaparece automaticamente. Card permanece, mas com 100%.

### P: Posso ter múltiplos parcelamentos?
**R:** Sim! Crie quantos precisar. Todos aparecem no fluxo de caixa.

### P: Os dados ficam salvos?
**R:** Sim! No LocalStorage. Recarregue a página e tudo continua lá.

### P: Como deletar um parcelamento?
**R:** Clique em 🗑️ no card. Confirmação. Pronto!
