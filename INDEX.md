## 🎓 Curva de Aprendizado

### Nível 1: Iniciante (5 min)
1. Leia [README.md](./README.md)
2. Inicie o app: `npm run dev`
3. Faça login
4. Clique em "Parcelado"

### Nível 2: Básico (15 min)
1. Leia [INSTALLMENTS_GUIDE.md](./INSTALLMENTS_GUIDE.md) - Seção "Entrada de Dados"
2. Crie seu primeiro parcelamento
3. Veja o card aparecer
4. Visualize no "Fluxo de Caixa"

### Nível 3: Intermediário (30 min)
1. Leia [INSTALLMENTS_GUIDE.md](./INSTALLMENTS_GUIDE.md) - Completo
2. Teste todos os atalhos
3. Edite um parcelamento
4. Delete e recrie outro
5. Planeje múltiplos parcelamentos

### Nível 4: Avançado (1 hora)
1. Leia [TECHNICAL_INSTALLMENTS.md](./TECHNICAL_INSTALLMENTS.md)
2. Entenda a arquitetura
3. Explore o código em App.jsx
4. Execute os testes recomendados

### Nível 5: Expert (2 horas)
1. Estude [IMPLEMENTATION_SUMMARY.md](./IMPLEMENTATION_SUMMARY.md)
2. Revise todo o código
3. Implemente extensões
4. Propor melhorias
